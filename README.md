# Buscador de Recetas 🍽️
Aplicación web para buscar recetas por categoría, visualizar sus detalles y guardarlas en favoritos.

## 📸 Preview
<img width="1887" height="917" alt="image" src="https://github.com/user-attachments/assets/8fe46c51-c714-4ecc-bc1b-c3781f071dab" />

Este proyecto fue desarrollado como práctica de JavaScript, trabajando con consumo de APIs, manipulación del DOM, Bootstrap y almacenamiento local.

## 🚀 Funcionalidades
- Obtener categorías de recetas desde una API
- Buscar recetas por categoría
- Visualizar el detalle de cada receta en un modal
- Mostrar ingredientes e instrucciones
- Guardar recetas favoritas
- Eliminar recetas de favoritos
- Persistencia de favoritos con localStorage

## 🛠 Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Bootstrap
- Fetch API
- localStorage

## 📚 Conceptos practicados
- Consumo de APIs REST
- Promesas con Fetch
- Manipulación del DOM
- Eventos en JavaScript
- Renderizado dinámico
- Uso de modales y toast con Bootstrap
- Persistencia con localStorage
